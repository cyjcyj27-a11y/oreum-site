    🔒 고른 파일은 이 기기의 브라우저 안에서만 합쳐집니다. 어디에도 올라가지 않으니 계약서·신분증 사본도 안심하고 쓰세요.

    PDF 합치기는 PDF 파일 여러 개와 사진(JPG·PNG)을 하나의 PDF로 병합하는 무료 웹 도구입니다. 파일은 서버로 올라가지 않고 이 브라우저 안에서만 합쳐집니다.

    PDF 파일 합치는 방법

    1. 파일 고르기를 눌러 합칠 PDF와 사진을 한꺼번에 고릅니다. PC에서는 끌어다 놓거나 Ctrl+V로 붙여 넣어도 됩니다.
    2. ▲▼ 단추나 마우스로 끌어서 순서를 맞춥니다. 이름순을 누르면 파일 이름 순서로 한 번에 정렬됩니다.
    3. 일부 페이지만 넣고 싶으면 그 파일의 페이지 칸에 1-3, 5처럼 적습니다. 비워 두면 전체가 들어갑니다.
    4. 파일 이름을 정하고 PDF 합치기를 누르면 합친 파일이 바로 저장됩니다.

    파일이 서버로 가지 않습니다

    PDF 병합 사이트는 대부분 파일을 자기 서버에 올려서 합친 뒤 돌려줍니다. 이 도구는 파일을 올리지 않고, 브라우저가 내 기기 안에서 직접 읽고 합칩니다. 그래서 계약서, 신분증 사본, 통장 사본처럼 남의 서버에 올리기 꺼려지는 서류도 쓸 수 있습니다. 페이지를 연 뒤 인터넷을 끊어도 그대로 합쳐지는 것으로 확인할 수 있습니다.

    자주 묻는 질문

    PDF 합치기는 무료인가요? 횟수 제한이 있나요?

    무료입니다. 회원가입이 없고, 하루 몇 번이나 파일 몇 개 같은 제한도 없습니다.

    파일이 서버에 올라가나요?

    아니요. 고른 파일은 이 기기의 브라우저 안에서만 읽고 합칩니다. 오름게임즈 서버를 포함해 어디에도 보내지 않습니다. 페이지를 연 뒤 인터넷을 끊어도 합쳐집니다.

    PDF 병합과 PDF 합치기는 같은 건가요?

    같은 말입니다. 여러 PDF 파일을 순서대로 이어 붙여 파일 하나로 만드는 것을 PDF 병합, PDF 파일 합치기라고도 부릅니다.

    사진도 PDF에 넣을 수 있나요?

    네. JPG, PNG, WEBP 사진은 한 장이 A4 한 쪽이 됩니다. 폰으로 찍어 옆으로 누운 사진도 바로 세워서 넣습니다. 아이폰 HEIC 사진은 아직 넣을 수 없습니다.

    원하는 페이지만 골라 합칠 수 있나요?

    네. 파일마다 있는 페이지 칸에 1-3, 5처럼 적으면 그 쪽만 들어갑니다. 비워 두면 전체가 들어갑니다.

    휴대폰에서도 되나요?

    네. 파일 고르기로 폰에 있는 PDF와 사진을 넣고 ▲▼ 단추로 순서를 바꿉니다. PC에서는 끌어다 놓기와 Ctrl+V 붙여넣기도 됩니다.

    암호가 걸린 PDF도 합칠 수 있나요?

    아니요. 암호가 걸린 PDF는 목록에 따로 표시되고 합칠 때 빠집니다. 암호를 푼 파일을 넣어 주세요.
