ネコ用ゲーム 猫のタップゲーム

🎮 ゲームを始める

ネコ用ゲームは、いろいろなものが画面を走り回り、タップするとキュッと鳴ってはじけるタップゲームです。猫と幼児のために作りました。無料、ブラウザで遊べて、ダウンロード不要です。

うちの猫のために作りました。

START を押すと、ひとつのものが出てきます。魚、チョウ、ボール、星、ハート、ネズミ、虫、羽根、赤い点、毛糸玉のどれかです。画面じゅうを走り回り、いきなり向きを変えたり、壁にはね返ったり、8の字を描いたり、ぴたっと止まってから急に飛び出したりします。指や猫の手でタップすると、ぺちゃっとつぶれてキュッと鳴り、小さなハートになってはじけて、別のものに替わります。

画面に出ているのはいつもひとつだけです。はじけると次が出てきて、しばらく放っておくと自分から去っていき、別のものが来ます。ステージも終わりも GAME OVER もないので、猫のために START を押したら、あとは何も触らなくて大丈夫です。大きな魚、ボール、星はゆっくり動くので幼児向け、小さなネズミ、虫、赤い点は速く動くので猫向けです。当たり判定は広めで、少し外れても当たりになります。何もないところをタップすると波紋が広がり、小さくポンと鳴ります。

ボタンは効果音の切り替えだけで、ゲーム中は画面が消えません。ピンチ操作の拡大と長押しは止めてあるので、猫の手が画面に乗っても設定は変わりません。音はファイルを読み込むのではなくブラウザがその場で作っているので、ページを開いたあとは通信が切れても遊び続けられます。タブレットを床に平らに置くのにぴったりで、縦画面でも横画面でも使えます。

バグや遊びにくいところを見つけたら教えてください

よくある質問

操作方法は？

動いているものを指や猫の手でタップします。PCではマウスでクリックします。ボタンは効果音の切り替えだけで、GAME OVER もありません。

猫は本当に反応しますか？

猫によって違います。ネズミ、虫、赤い点は猫が追いかけたくなる大きさと速さにしてあり、猫の手が触れるとすぐに音が鳴ります。爪よけに画面保護フィルムを貼るのがおすすめです。

幼児でも遊べますか？

遊べます。大きな魚、ボール、星はゆっくり動き、少し外れても当たりになります。文字もボタンもないので、START を押してあげるだけです。

画面が消えたり拡大されたりしませんか？

ゲーム中は画面が消えず、ピンチ操作の拡大と長押しも止めてあります。ホームボタンと通知は止められないので、スマホよりタブレットのほうが安心です。

何か保存されますか？

スコアは記録しません。効果音の設定だけをブラウザに保存します。サーバーには何も送りません。
