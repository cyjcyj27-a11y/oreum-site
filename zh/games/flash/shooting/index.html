夜市打枪 射击摊游戏

🎮 开始游戏

夜市打枪是一款免费网页游戏，在韩国夜市的射击摊上，用软木塞枪把易拉罐，瓶子和鸭子打下架子，赢取毛绒玩具。在浏览器里就能玩，无需下载。

我们把韩国夜市里那种做了手脚的射击摊搬了进来。
明明打中了易拉罐，它却几乎不倒，好不容易把准星调准了，软木塞还是会打偏。
真正的夜市每一局都要花钱，这个游戏是免费的，想重来多少次都行。

准星从来不会停稳。它随着呼吸一上一下，手会抖，扣扳机的瞬间枪也会抖一下。每一局准星还会有点歪，所以要看第一发软木塞落在哪里，再修正瞄准。软木塞和真的一样很轻，飞得越远掉得越多。

底排的易拉罐底部加了配重，打中间只会让它晃一晃，就算倒了，也要掉下架子才算数。瓶子和木瓶只要打倒就行，木鸭子在轨道上移动，气球会爆，打中烟花箱会把旁边的靶子都炸飞。软木塞用完还有靶子没打下来就是 GAME OVER，按 RETRY 马上重打这一关。

一共24关，第一次通过双数关卡就能赢一个毛绒玩具。从熊，兔子，小猫一直到恐龙，集齐十一个，再在第24关赢下巨型熊，就能看到结局。打下靶子赚的金币可以买长步枪，双管枪，三连发，霰弹枪和炮弹枪，还能加软木塞，另外还有12个任务。看摊的是一只浣熊，你软木塞用光时它会哈哈大笑。

常见问题

为什么打中了易拉罐却不倒？

和真的游乐场易拉罐一样，底排的底部加了配重，打中间只会晃一晃。倒下的易拉罐还要掉下架子才算数。瓶子和木瓶打倒就算。

准星为什么会晃？

游戏里做了手抖和呼吸。扣扳机时枪也会抖一下，每局准星还会有点歪。越好的枪晃得越少，散布也越小。

软木塞用完了会怎样？

还有靶子没打下来就是 GAME OVER。按 RETRY 就能从头重打同一关，重来不花任何东西。

一共几关，结局是什么？

一共24关。每个双数关卡第一次通过时会给一个毛绒玩具，通过第24关就能赢下巨型熊，看到结局。

有哪些枪？

六把，软木塞枪，长步枪，双管枪，三连发，霰弹枪和炮弹枪。用打靶赚来的金币在商店里买，AMMO +1 最多能买五次。

有哪些靶子？

易拉罐金字塔，玻璃瓶，沿着轨道移动的木鸭子，会弹回来的铁靶，气球，木瓶和烟花箱。烟花箱会爆炸，把旁边的靶子都炸飞。

能从头开始吗？

在标题画面按 NEW GAME，就会清掉关卡，金币和毛绒玩具，从 STAGE 1 重新开始。
