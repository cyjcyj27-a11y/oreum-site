爬梯子 鬼脚图抽签游戏

🎮 开始游戏

爬梯子是一款免费的网页游戏，玩的是韩国的爬梯子游戏，也叫鬼脚图或阿弥陀签，沿着白板上画的梯子走下去，决定谁拿到哪个结果。无需下载，打开浏览器就能玩。

办公室白板上用黑色马克笔画着一张梯子。顶上贴着写名字的黄色便利贴，底下的结果被粉色便利贴盖住。点一个名字，这个人颜色的马克笔就会往下走，每遇到一根横杠就转弯，走到底时粉色便利贴会掉下来，露出结果。不是 Pass 的结果会用那个人的颜色圈起来。

人数可以选2到50人。名字一开始是编号，结果一开始是一个 Win，其余都是 Pass。可以加更多中签名额，从第1名开始填名次，也可以在每个格子里写自己的结果，比如买咖啡或者值日打扫。粘贴一行一个名字的名单，就会一次填满下面的格子。人多的时候，梯子会横过来，往下滚动就能跟着看。

Reveal All 会让所有人同时往下走，走完后会出现结果单，中签的人排在前面。可以把结果复制成文字，也可以发送链接，打开链接的人会在同一张梯子上看到同样的名字。Shuffle 和 Again 会重新画横杠，并重新打乱结果的位置。名字和结果不会保存，刷新就会重来。

常见问题

韩国爬梯子游戏怎么玩？

每个名字在一条竖线的顶上，每个结果在底下。从你的名字沿着线往下走，每遇到一根横杠，就必须沿着它走到旁边那条线。最后停在哪里，就是你的结果。不会有两个人停在同一个地方。

爬梯子公平吗？

公平。梯子每根横杠只会让你往旁边移一条线，所以如果结果的位置一直不变，离 Win 近的人就更容易中。所以每次画新梯子时，结果格都会重新打乱。我们用9人、20人、50人各跑了几千轮，确认每个人中签的次数都差不多。

可以不止一个人中签吗？

可以。选 Win / Pass 时，按 Win 旁边的加号就能增加中签名额。Ranks 会把结果从第1名填到最后一名，也可以点任意结果格写自己的内容。

可以粘贴名单吗？

可以。复制一行一个名字的名单，粘贴到第一个名字格里。会按顺序填满下面的格子，格子不够时人数会自动增加。结果也可以用同样的方法粘贴。

可以分享结果吗？

Copy 会把每个名字和结果各占一行列出来，最后加上链接，Link 只复制网址。打开链接的人会看到同样的名字、结果和梯子，还可以自己点名字走一遍。

手机上50个人也能玩吗？

如果所有人都能横着排进屏幕，梯子就是竖着的。人更多时，梯子会横过来，名字在左边，结果在右边，往下滚动跟着看。单独让一个人走时，画面会跟着他的马克笔移动。
