给猫玩的游戏 猫咪点击游戏

🎮 开始游戏

给猫玩的游戏是一款点击游戏，各种东西在屏幕上跑来跑去，点一下就会吱的一声爆开。专门给猫咪和幼儿做的。免费，在浏览器里玩，免安装。

这是给我家猫做的。

按下 START，就会出来一样东西，可能是小鱼，蝴蝶，球，星星，爱心，老鼠，虫子，羽毛，红点或者毛线球。它会在屏幕上到处跑，冷不丁掉头，撞墙弹回来，绕着8字转圈，或者停一下再猛地窜出去。用手指或猫爪点它一下，它就会一扁，吱的一声，炸成一堆小爱心，再换成别的东西。

屏幕上永远只有一样东西。点爆了会出来下一个，放着不管一阵子，它也会自己离开，换另一个来。没有关卡，没有结束，也没有 GAME OVER，所以给猫按下 START 以后就什么都不用再碰了。大的小鱼，球和星星动得慢，适合幼儿，小的老鼠，虫子和红点动得快，适合猫咪。判定范围很宽，差一点点没点中也算，点到空白处会泛起一圈波纹，发出轻轻的啵一声。

唯一的按钮是声音开关，游戏运行时屏幕不会熄灭。双指缩放和长按都被屏蔽了，猫爪踩在屏幕上也改不了任何设置。声音是浏览器现场生成的，不是加载文件，所以页面打开以后就算断网也能一直玩。很适合把平板平放在地上，竖屏横屏都可以。

常见问题

怎么操作？

用手指或猫爪点一下会动的东西。电脑上用鼠标点。唯一的按钮是声音开关，也没有 GAME OVER。

猫真的会有反应吗？

每只猫都不一样。老鼠，虫子和红点的大小和速度都是按猫会去追的程度设计的，猫爪一碰马上就会出声。贴一张屏幕保护膜可以防爪子。

幼儿能玩吗？

能。大的小鱼，球和星星动得慢，差一点点没点中也算。没有文字也没有按钮，只要帮他们按下 START 就行。

屏幕会熄灭或者被放大吗？

游戏运行时屏幕不会熄灭，双指缩放和长按也被屏蔽了。主屏幕键和通知没法屏蔽，所以用平板比用手机更省心。

会保存什么吗？

不记分数。只有声音设置保存在浏览器里。不会发送到任何服务器。
