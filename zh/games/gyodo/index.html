狱警24小时 反向塔防游戏

🎮 开始游戏

狱警24小时是一款免费的反向塔防游戏，你要用狱警，铁门和 CCTV，拦住从牢房冲向围墙的囚犯。无需下载，打开浏览器就能玩。

大多数塔防游戏里，敌人是从外面打进来的。这里正好反过来，囚犯从里面往外跑。牢门一开，穿浅蓝色囚服的囚犯就朝围墙的缺口狂奔。点一下地面安排狱警，他会朝从身边经过的囚犯扔手铐。囚犯的胆量耗光了，就会被铐上带走。每抓一个都有金币，金币再拿去买更多装备。

装备能挡路。把铁门排成一列，囚犯就得绕远路，沿着绕路一路排满狱警，就能一个一个抓住他们。永远不能把路完全堵死，每一波开始前，囚犯要走的路线会用红点标在地上。

囚犯一共七种。跑得快的飞毛腿，会砸铁门的大块头，在地下钻行，每隔几秒探一次头的挖地道的，穿着偷来的狱警制服的伪装犯，还有举着锅盖成群冲锋的暴动犯，会一天一天加进来。挖地道的和伪装犯被 CCTV 发现后就会一直现形，伪装犯从狱警身边走过也会露馅。

每天的值班从早上6点点名开始，每个时段都会有囚犯冲出来。第1到第3天到傍晚6点共五波，从第4天起还有晚上10点熄灯的第六波。熄灯后，除了探照灯的光照范围，狱警的射程都会变短。一天里有五个囚犯翻过围墙就 GAME OVER，要重玩那一天。根据逃掉的人数，最多能拿三星。

常见问题

把路完全堵死会怎样？

那里放不下装备。从牢门到围墙缺口至少要留一条路，不能放的格子会变红。

囚犯翻过围墙会怎样？

上方的警示灯会亮一盏。五盏全亮就 GAME OVER，越狱王一逃出去这一天就直接结束。

看不见的囚犯怎么抓？

挖地道的只有每隔几秒探头时才能打到。他从 CCTV 附近经过后就会一直现形。伪装犯会被 CCTV 识破，从狱警身边走过也会露馅。

装备能升级或卖掉吗？

点一下放好的装备，可以 UP 两次，也可以按花费金币的70%卖掉。

一天失败了要从头开始吗？

不用，只重来那一天。打过的日子和星星都会留在值班表上，随时可以重玩。
