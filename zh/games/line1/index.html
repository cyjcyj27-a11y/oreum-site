1号线恶人 像素塔防游戏

🎮 开始游戏

1号线恶人是一款免费的塔防游戏，你要用站务员，保安和护栏，拦住登上首尔地铁1号线车厢的恶人，不让他们走到下一节车厢。无需下载，打开浏览器就能玩。

你守着1号线列车的一节车厢。按下发车按钮，列车开到下一站，车门打开，恶人就上车了。他们会朝车厢右边尽头的连接门走，每过去一个就多一次投诉。一关里投诉满五次就 GAME OVER。

你要用摆在车厢地上的人和装备拦住他们。站务员吹哨子，社会服务员弱但便宜，保安会抓住恶人拖慢他们。把护栏排起来，恶人就得绕远路，但永远不能把路完全堵死。每抓一个都有金币，金币再拿去买更多人手。

恶人一共十六种，随着关卡一种一种加进来。在传教士旁边，装备会变慢，小贩会停下来摆摊，躺座大叔被打掉一半体力后会躺在地上回血，鸽子和吊环引体男会从护栏上飞过去。炸鸡小伙和生鱼片烧酒大叔会用气味把附近的装备熏晕，遛狗乘客靠的是狗屎。说教大爷只听保安和铁路警察的。

每十关会有一个区间 Boss 上车。黄金铠甲将军和小贩之王会砸烂护栏，鸽子王会叫来一群鸽子，短箫杀人魔跑得飞快，还会用短箫把附近的装备打晕。第70关的1号线大恶魔会轮流使出前面所有 Boss 的招数。

过关后从三张车票卡里选一张，可以加初始金币，或者让装备变强，金框卡效果更大。一次投诉都没有就能拿三星。遇到的每个恶人都会收进图鉴，打到第70关就能看到结局。

常见问题

恶人走过连接门会怎样？

上方的投诉灯会亮一盏。全部亮起就 GAME OVER，Boss 一走过去这一关就直接结束。登山社团的每个人都算两次投诉。

用护栏把路全堵死会怎样？

那里放不下护栏。从车门到连接门至少要留一条路，而且鸽子和吊环引体男本来就能飞过护栏。

选过的卡会一直有效吗？

会。选过的每张卡在后面的关卡里都一直有效，同一张卡可以叠到上限。打过 Boss 关时，第一张一定是金框卡。

这些是1号线真实的车站吗？

是的。从逍遥山到新昌，1号线真实的站名会按区间依次出现，每次停站都会显示站台和站牌。

输给 Boss 要从头开始吗？

不用，只重来那一关。打过的关卡和星星都会留在线路图上，随时可以重玩。
